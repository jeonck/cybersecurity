Offensive security uses attacker techniques defensively: penetration testing methodologies, structured vulnerability research, and red team exercises validate that controls actually hold up under a real adversarial test, rather than only on paper. This section collects the core methodologies and concepts referenced throughout the rest of this knowledge base.
