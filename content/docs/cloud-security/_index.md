Cloud security extends traditional security governance into environments where infrastructure is provisioned on demand, ownership boundaries are shared with the provider, and misconfiguration — not just intrusion — is the dominant risk. This category collects the working documents that keep cloud accounts, workloads, and data accountable: who can access what across providers, which assets actually exist, whether backups can really be restored, how incidents are tracked when they span accounts and services, and what a secure baseline configuration looks like.

These artifacts are typically owned and maintained by the cloud security or platform engineering team, working alongside DevOps/SRE for asset and configuration data and the security operations team for incident handling. They form the evidence base used in cloud security posture reviews, provider audits, and post-incident analysis.
